# Konfigurace aplikace

Tato sekce popisuje možnosti konfigurace aplikace Spectoda.

## Základní nastavení

### Obecné parametry
- Název aplikace
- Jazyk rozhraní
- Časové pásmo

### Bezpečnostní nastavení
- Doba platnosti session
- Povolené IP adresy
- Šifrování dat

## Pokročilá konfigurace

### Databázové připojení
- Typ databáze
- Připojovací řetězec
- Pool připojení

### Integrace
- API klíče
- Webhook endpointy
- Externí služby
